# Hani Ibtissem

This folder contains a polished, responsive one-page portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure and sections
- `styles.css` — all visual design, responsive layout, glassmorphism, animations
- `script.js` — dynamic project gallery, filters, mobile menu, reveal animation
- `assets/` — portrait, fixed animated background video, portrait, CV, and project cover placeholders
